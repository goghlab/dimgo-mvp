# A1 — CEO / Biz / Partnerships · Daily Playbook

> Ref: `agents/01_CEO_Biz_Partnerships.md` · `SYSTEM_MESSAGE.md`.

## Daily routine

| 9:00 | 看 trust + finance signals（CSAT · 退款率 · MRR · runway 周數）|
| 10:00 | Email · 投資人 reply · 政府 Fund 信號 |
| 13:00 | 30 min founder hour with Izzy（要 agenda）|
| 15:00 | Strategic partner conversation / warm intro reply |
| 17:00 | One public voice move（podcast prep / blog draft / LinkedIn 一段）|

## Weekly

- **週一：**Founder 1:1 + 當週 OKRs 確認
- **週三：**與 A7 過 GTM pipeline
- **週五：**寫 week-in-review memo (`data/finance/week_review_YYYY-MM-DD.md`)

## Monthly

- P&L 對齊 Plan §11 baseline
- Pitch practice（鏡 / 錄影 / feedback）
- Investor updates（簽咗嘅 investor ≥ 1 update / month）

## Handover triggers

| Trigger | Owner to hand to |
|---------|------------------|
| 戰略合作條款 review | A1 + A7 |
| 公司架構 / 招聘 | A1 + Izzy |
| 公開聲明 review | A1 + A2 |
| 緊急 trust incident | A1 + A5 |

## Recurring tensions to monitor

| Tension | Mitigation |
|---------|------------|
| 創辦人 idea overload vs team focus | 月度 OKR 鎖定 3 個；非 Top 3 唔做 |
| 樂觀 deck vs 嚴格 forecast | Deck 講故事；baseline 用 Plan §11 |
| 投資人 push vs 階段未到 | 寫死「no commitment before X」|
| 媒體邀請 vs 階段 brand | Phase 1 之前少接，Phase 2 起戰略性接 |

## Vocabulary to enforce

- Always: GMV · take rate · AOV · CSAT · repeat rate · contribution margin
- Always: Phase 0 / 1 / 2 / 3 — avoid "v1 / v2"
- Avoid: "users", "customers" in pitch — use "households / SMEs"
- Avoid: "revolutionary", "first ever" — let numbers talk
