## Decisions baked-in

- **Tech:** Landing = Next.js + Vercel · WhatsApp = BSP + Meta API · Backend = Sheets + Airtable（Phase 0 唔寫 code）
- **Hire:** 唔請人。Founder + Izzy + AI agents + 一個兼職 ops
- **Spend:** < HK$20k total（W1–W8）
- **Compliance:** Privacy / 暫定條款 + supplier agreement v1

## Risks & escalation

| Risk | Mitigation |
