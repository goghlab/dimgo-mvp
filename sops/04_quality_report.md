# SOP 04 — Quality Control Report

> Required after every non-trivial task.
> Format aligned to MEMORY.md Quality Control Protocol.

---

## Use this template

```
## 📋 Quality Control Report — [task title]

### ✅ Status
- Lead agent:
- Backup agents:
- Started:
- Finished:
- Outcome: ✅ done / ⚠️ partial / ❌ blocked

### 📊 Evidence
- Numbers (orders / suppliers / CSAT / GMV / take rate / runway):
- Records linked (data/*):
- Documents created/updated:

### ✅ Quality checklist
- [ ] Affected agents reviewed
- [ ] Audit trail intact
- [ ] Money events traced end-to-end
- [ ] Confirmation / consent gates respected
- [ ] Sponsor tags disclosed where relevant
- [ ] PDPO compliance confirmed
- [ ] Refund policy honoured
- [ ] Supplier agreement honoured
- [ ] Next phase gate unaffected (or note if affected)

### ⚠️ Issues & mitigations
- Issue 1:
- Issue 2:

### 🎯 Next actions
- For [agent]:
- For [agent]:
- For [Izzy]:

### 📎 Attachments
- File / link 1
- File / link 2
```

## When to send

| Trigger | Who to send to |
|---------|----------------|
| Phase milestone hit / missed | Izzy + A1 |
| Money event anomaly | Izzy + A1 + A5 + A4 |
| Supplier incident | A1 + A5 + A6 |
| Public-launch prep step | Izzy + A1 |
| Compliance red-flag | Izzy + A1 + legal advisor |

## Tone

- 事實為先，唔好寫 OK 之後冇 evidence
- 唔好淡化問題 · 直接 tag 「⚠️」
- 每個 action 都有 owner + due date
